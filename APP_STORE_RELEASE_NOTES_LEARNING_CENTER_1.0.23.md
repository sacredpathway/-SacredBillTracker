# App Store Release Notes - Sacred Bill Tracker 1.0.23 (61)

## What's New

Sacred Bill Tracker now includes a built-in Learning Center to help you understand every major part of the app.

- New searchable Learning Center in Settings.
- Step-by-step guides for bills, budgets, income, reports, calendar tools, partner budgeting, profiles, Receipt Jar, AutoTrack, Sacred Focus+, subscriptions, and account settings.
- Beginner-friendly Getting Started guidance for new users.
- FAQs and troubleshooting for upgrades, restores, notifications, sync, and data safety.
- "Take Me There" shortcuts from help articles to supported app areas.
- Offline access so help content remains available inside the app.

## Internal Review Notes

- The Learning Center is available from `Settings -> Help and referrals -> Learning Center`.
- No subscription pricing, promotional offers, backend settings, or unreleased lifetime-purchase behavior are included in this release candidate.
- DEBUG-only UI-test routing is excluded from Release builds.
